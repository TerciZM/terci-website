# Terci Communications website

Catalyst Slate front-end for Terci Communications Limited.

## Catalyst Slate settings

- Framework: Vite
- Root path: `./`
- Branch: `main`
- Build command: `npm run build`
- Output directory: `dist`

The public website is ready for Slate deployment. Product administration,
uploads, analytics and administrator authentication are added in the Catalyst
backend phase.
